# AppTravel Group · protótipo navegável

Organize a sua viagem e a do seu grupo com o app.

**Abrir o protótipo:** https://flavioantoniojr.github.io/apptravel-prototipo/

- No celular, abre em tela cheia, como um app. Use "Ver demonstração" para ver o fluxo sozinho.
- No computador, mostra a moldura de celular e o mapa das etapas ao lado.

Dados de exemplo: notas, avaliações, comentários e agências são ilustrativos.
